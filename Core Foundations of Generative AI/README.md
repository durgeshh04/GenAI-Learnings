<!-- Theory of GenAI -->

## Q:1 What is AI?

- AI is the discipline of building system that make probabilistic decision instead of deterministic decisions from rules.

## Q:2 What AI Is NOT?

- Just LLMs
- Just chatbots
- Just deep learning
- Just automation
- Just data science
- Those are subsets or tools.

## Q:3 What is LLM?

- A Large Language Model is a type of AI system which predicts and generate text by learning patterns from massive amounts of language data.

## Q:4 What is Tokenization?

- Tokenization is the process of breaking text into smaller units called tokens that a model can process.
- These tokens are then mapped to numbers (IDs), because neural networks only operate on numbers.
###  So the full pipeline is:
- Text → Tokens → Token IDs → Model
